# 검증 판정 기준

구조 검증과 시각 렌더링은 서로 다른 검사입니다. 한쪽의 성공으로 다른 쪽을 자동 추정하지 않습니다.

## 판정

### PASS

다음 조건을 모두 실제로 확인한 경우에만 사용합니다.

- PPTX가 정상적으로 열리고 구조 검증이 완료됨
- 16:9, 슬라이드 수, 필수 개체와 편집 가능성이 요구사항에 맞음
- 모든 슬라이드에 발표자 노트가 있고 스크립트·발문·`[Sources]`를 포함함
- 글꼴 적용 또는 실제 대체 글꼴이 확인됨
- 요청된 전체 시각 렌더링이 완료되고 잘림·겹침·대비·가독성 검수가 끝남
- 기준 렌더러와 실제 렌더러가 일치하거나 차이가 검토됨

### WARN

핵심 산출물과 구조 검증은 유효하지만 환경 차이 또는 미수행 검사가 남은 경우입니다.

- Pretendard 대신 실제 설치된 한글 글꼴을 사용함
- 기준 렌더러가 아닌 호환 렌더러를 사용함
- 미검증 엔진이 남아 있음
- 일부 슬라이드의 시각 렌더링을 수행하지 못함
- 사람의 화면 확인이 필요한 항목이 있음

`WARN`은 `PASS`로 바꾸어 보고하지 않습니다. 남은 확인 사항을 구체적으로 적습니다.

### FAIL

다음 중 하나라도 해당하면 제작 또는 완료 보고를 중단합니다.

- 제작 도구가 전혀 없음
- PPTX가 손상되어 열리지 않거나 구조를 해석할 수 없음
- 구조 검증을 수행할 수 없음
- 필수 발표자 노트가 하나라도 누락됨
- 입력·출력·승인 정보가 없어 작업 범위를 결정할 수 없음
- 원본을 수정·이동·삭제해야만 진행되는 상황

## 보고 형식

```text
구조 검증: PASS/WARN/FAIL — 확인한 항목과 도구
시각 렌더링: PASS/WARN/FAIL — 렌더링 범위와 확인한 항목
기준 렌더러: <엔진·버전>
실제 사용 렌더러: <엔진·버전 또는 미실행>
미검증 엔진: <엔진명 또는 해당 없음>
글꼴: <Pretendard 또는 실제 대체 글꼴>
확인 필요: <사람이 확인할 항목 또는 해당 없음>
```

검증하지 못한 사실은 추정하지 않고 `WARN` 또는 `FAIL`로 남깁니다.
