# 호환 모드

호환 모드는 권장 하위 스킬이나 기준 렌더러가 현재 환경에 없을 때도 가능한 범위에서 PPTX 작업을 진행하는 운영 방식입니다. 입력·원본 보호·발표자 노트·검증 기준은 일반 모드와 같습니다.

## 도구 선택

1. `presentations:Presentations`와 그 기준 렌더러가 있으면 우선 사용합니다.
2. 없으면 현재 운영체제에 설치되어 실제 실행되는 로컬 PPTX 제작 도구를 선택합니다.
3. 구조 검증은 `scripts/validate_pptx.py`를 우선 사용하고, 없거나 실행할 수 없으면 ZIP/XML 또는 PPTX 라이브러리 재열기 검사로 대체합니다.
4. 렌더링은 설치된 PowerPoint 또는 LibreOffice 계열 등 실제 실행 가능한 엔진을 사용합니다.
5. 기준 엔진과 실제 엔진이 다르면 두 엔진의 차이를 숨기지 않고 보고합니다.

`python-pptx`처럼 제작은 가능하지만 렌더링을 제공하지 않는 도구만 있는 경우에는 구조 검증까지만 수행할 수 있습니다. 시각 검수는 수행하지 않은 것으로 남기며 완료 보고에서 `WARN` 또는 `확인 필요`로 표시합니다.

## 글꼴 호환

- Pretendard가 있으면 지정 글꼴로 사용합니다.
- Pretendard가 없으면 실제 설치된 한글 글꼴 중 하나를 선택합니다.
- 대체 글꼴은 이름을 기록하고 `확인 필요`를 함께 표시합니다.
- 존재하지 않는 글꼴을 지정하거나 설치를 가장하지 않습니다.

## 모드별 결과

| 조건 | 진행 | 결과 기록 |
|---|---|---|
| 권장 도구와 기준 렌더러 사용 가능 | 제작·구조 검증·시각 검수 | 일반 결과와 엔진 정보 |
| 권장 도구 없음, 로컬 제작·검증·렌더러 사용 가능 | 계속 | 호환 모드, 대체 도구·버전, 미검증 엔진 |
| 제작·구조 검증 가능, 렌더러 없음 | 구조 검증까지 진행 | 시각 검수 미수행, `WARN`·`확인 필요` |
| Pretendard 없음, 설치된 한글 글꼴 있음 | 계속 | 대체 글꼴명과 `확인 필요` |
| 제작 도구 전무 | 중단 | `FAIL`, 필요한 도구 안내 |
| PPTX 손상 또는 필수 노트 누락 | 중단 | `FAIL`, 수정 후 재검증 |

## 호환 모드 보고에 포함할 내용

- 호환 모드로 전환한 이유
- 사용한 제작·구조 검증·렌더링 도구와 버전
- 기준 렌더러, 실제 사용 렌더러, 미검증 엔진
- 지정 글꼴과 실제 사용 글꼴
- 구조 검증 결과와 시각 검수 결과를 분리한 판정
- 사람이 확인해야 할 환경 차이

호환 모드에서도 입력값과 주제를 임의로 만들지 않으며, 기존 승인 절차·원본 읽기 전용 원칙·모든 슬라이드 발표자 노트 규칙을 유지합니다.
