# 제작 전 환경 사전 점검

호환 모드는 제작 전에 환경을 확인하고, 확인 결과를 제작·검수 보고에 남깁니다. `scripts/preflight.py`를 실행하거나 아래 항목을 같은 수준으로 수동 점검합니다.

## 점검 항목

### 입력 계약

- 대상 자료의 실제 경로가 존재하고 읽기 가능한가
- 주제가 제공되었는가, 또는 주제 선정을 위임받았는가
- 출력 폴더와 파일명이 정해졌고 기존 파일과 충돌하지 않는가
- 화면 비율, 최소 글자 크기, 디자인 지침, 발표자 노트 규칙이 확인되었는가
- 웹 검색·외부 이미지·외부 데이터 사용 허용 여부가 확인되었는가

빈 값은 임의의 주제·경로·사양으로 채우지 않습니다.

### 제작·구조 검증 도구

다음 역할별로 실제 사용 가능한 도구와 버전을 기록합니다.

| 역할 | 우선순위 | 호환 모드 대안 |
|---|---|---|
| PPTX 제작 | `presentations:Presentations`가 제공하는 방식 | 설치된 PowerPoint 자동화, LibreOffice 계열, `python-pptx` 등 로컬 제작 도구 |
| PPTX 구조 검증 | `scripts/validate_pptx.py` | ZIP/XML 검사 또는 사용 가능한 PPTX 라이브러리의 재열기 검사 |
| 슬라이드 렌더링 | `presentations:Presentations`가 안내하는 기준 렌더러 | 설치된 PowerPoint, LibreOffice 계열 등 실제 실행 가능한 로컬 렌더러 |

제작 도구가 하나도 없거나 구조 검증을 수행할 방법이 없으면 `FAIL`로 중단합니다. 기준 렌더러가 없으면 가능한 렌더러로 계속하거나, 렌더러도 없을 때 시각 검수 미수행을 `WARN`으로 남깁니다.

### 글꼴

1. Pretendard가 실제 설치되어 있는지 운영체제의 글꼴 목록에서 확인합니다.
2. 없으면 플랫폼별 글꼴 목록에서 한글 글리프를 지원하는 **실제 설치 글꼴**만 후보로 삼습니다.
3. 선택한 대체 글꼴명, 확인 방법, 미확인 글꼴 엔진을 기록합니다.
4. 설치되지 않은 글꼴을 이름만 지정하거나 자동 설치하지 않습니다.

Pretendard 미설치는 호환 모드에서 진행할 수 있지만, 대체 글꼴명과 `확인 필요`를 반드시 보고합니다. 한글 글꼴을 확인할 수 없으면 중단합니다.

### 렌더러 기록

점검 결과에 다음 세 필드를 분리해 기록합니다.

- **기준 렌더러:** 원래 검수 기준으로 삼은 엔진. 보통 `presentations:Presentations`가 안내하는 엔진
- **실제 사용 렌더러:** 이번 작업에서 실제로 실행한 엔진과 버전
- **미검증 엔진:** 실행하지 못했거나 결과를 비교하지 못한 엔진

렌더러가 다르면 동일한 결과라고 추정하지 않습니다.

## 수동 점검 기록 예시

```text
사전 점검: 2026-08-25
제작 도구: <도구명·버전>
구조 검증: <스크립트 또는 대체 방법>
기준 렌더러: <엔진·버전 또는 없음>
실제 사용 렌더러: <엔진·버전 또는 미실행>
미검증 엔진: <엔진명 또는 해당 없음>
글꼴: Pretendard <사용 가능/없음>; 대체 <실제 설치 글꼴명 또는 없음>
입력·출력·권한: <확인 결과>
판정: <PASS/WARN/FAIL>
```

이 기록은 최종 완료 보고에 요약합니다. 자동 탐지하지 못한 항목은 `확인 필요`로 둡니다.
